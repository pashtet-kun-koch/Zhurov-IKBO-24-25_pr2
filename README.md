# Инструмент визуализации графа зависимостей (Вариант №9)

## 1. Общее описание
CLI-утилита на Python 3 для анализа и визуализации графа зависимостей пакетов
формата JavaScript (npm) без использования сторонних библиотек и менеджеров
пакетов. Поддерживает работу с реальным реестром npm и локальными тестовыми
репозиториями, рекурсивный обход DFS, фильтрацию, обработку циклов, поиск
обратных зависимостей и генерацию диаграмм Mermaid.

## 2. Описание всех функций и настроек
| Флаг | Описание |
| --- | --- |
| `-p`, `--package` | Имя анализируемого пакета (обязательно) |
| `-r`, `--repo` | URL реестра npm или путь к тестовому файлу (обязательно) |
| `-t`, `--test-mode` | Включить режим работы с тестовым репозиторием |
| `-v`, `--version` | Версия пакета (обязательно в реальном режиме) |
| `-d`, `--max-depth` | Максимальная глубина анализа (по умолчанию 3) |
| `-f`, `--filter` | Подстрока для исключения пакетов |
| `--show-config` | Вывести параметры в формате ключ-значение (Этап 1) |
| `--direct-only` | Вывести только прямые зависимости (Этап 2) |
| `--reverse` | Вывести обратные зависимости (Этап 4) |

## 3. Описание команд для сборки проекта и запуска тестов
Проект использует только стандартную библиотеку Python 3 (сборка не требуется).

Выдать права на выполнение скрипта (macOS / Linux):
```bash
chmod +x run.sh
```

Запуск всех unit-тестов:
```bash
./run.sh test
```

## 4. Примеры использования

### Этап 1. Вывод конфигурации и обработка ошибок
```bash
./run.sh -p axios -r https://registry.npmjs.org -v 1.7.7 -d 2 --show-config
./run.sh -p axios -r bad_url -v 1.7.7
```

### Этап 2. Прямые зависимости пакета npm
```bash
./run.sh -p axios -r https://registry.npmjs.org -v 1.7.7 --direct-only
```

### Этап 3. Тестовый репозиторий (обычный граф, циклы, глубина, фильтр)
```bash
./run.sh -p A -r tests/sample_basic.txt -t -d 2
./run.sh -p A -r tests/sample_basic.txt -t -d 5 -f E
./run.sh -p A -r tests/sample_cycle.txt -t -d 5
```

### Этап 4. Обратные зависимости
```bash
./run.sh -p F -r tests/sample_basic.txt -t -d 5 --reverse
./run.sh -p D -r tests/sample_cycle.txt -t -d 5 --reverse
```

### Этап 5. Визуализация 3 реальных пакетов в Mermaid
```bash
./run.sh -p debug -r https://registry.npmjs.org -v 4.3.7 -d 2
./run.sh -p axios -r https://registry.npmjs.org -v 1.7.7 -d 2
./run.sh -p express -r https://registry.npmjs.org -v 4.21.1 -d 2
```

### Сравнение с `npm ls --all`
При сравнении вывода с `npm ls --all` возможны расхождения по следующим причинам:
1. `npm` строит дерево с учётом дедупликации (hoisting) и локального `package-lock.json`, а также учитывает `optionalDependencies` и `peerDependencies`.
2. Наш инструмент анализирует только секцию `dependencies` из метаданных реестра, ограничивает обход параметром `--max-depth` и исключает пакеты по подстроке `--filter`.
3. При разрешении semver-диапазонов (`^`, `~`) `npm` может выбрать более новую минорную версию, тогда как наш инструмент выбирает минимальную подходящую версию для стабильности и предсказуемости графа.
